**UltiBlock Pro** — универсальное расширение для браузера на Manifest V3, объединяющее блокировщик рекламы, YouTube & YouTube Music Premium, Enhancer + YT Tweaks, умную тёмную тему (Smart Dark Reader) и встроенный загрузчик видео, MP3 и фото.

---

## ✨ Основные возможности

1. **🛡️ Блокировщик рекламы и трекеров (DNR + Косметика + Stealth)**
   - Сетевые правила Declarative Net Request + скрытие баннеров + интерактивный выбор элемента на странице.
   - Нейтрализация видео-рекламы, попандеров, телеметрии и анти-адблок окон.
   - Белый список сайтов, чёрный список доменов и обновление облачной базы (+3500 рекламных серверов).
2. **▶️ YouTube & YouTube Music Premium**
   - Фоновое воспроизведение без пауз «Вы ещё смотрите?».
   - Встроенный **SponsorBlock** (автопропуск спонсорских вставок, интро, аутро).
   - **Return YouTube Dislike** — возврат счётчика дизлайков.
   - Авто-максимальное качество (4K / 1080p60), усиление звука HQ 200% Studio EQ, скорость до 4x, скриншот кадра, PiP (`Alt + P`), повтор видео.
   - Режим «Только аудио» в YouTube Music.
3. **🛠 Enhancer for YouTube & YT Tweaks**
   - Плавающий мини-плеер при чтении комментариев, регулировка громкости колёсиком мыши, режим кинотеатра, видео-фильтры и поворот кадра.
   - Скрытие YouTube Shorts, конечных заставок, рекомендаций, комментариев, квадратные углы, настройка колонок на главной (4/5/6).
4. **🌙 Smart Dark Reader (Умная тёмная тема)**
   - Два движка: **Smart DOM** (сохраняет оригинальные цвета фото и видео) и **GPU Filter** (ультра-быстрый 120 FPS).
   - 4 палитры: Midnight, Carbon, True OLED, Warm.
   - Настройка яркости, контраста, тёплого фильтра, автопропуск сайтов со своей тёмной темой, горячая клавиша `Alt + D`.
5. **📥 Встроенный загрузчик медиа**
   - Прямое скачивание видео с YouTube (с объединением аудио), музыки в MP3/WEBM, а также фото и видео с сайтов в фоновом режиме с ограничением скорости (анти-лаг для Discord).

## 🚀 Инструкция по установке для разных браузеров

Сначала скачайте расширение:
- Нажмите на GitHub **Code → Download ZIP** и распакуйте архив в постоянную папку (например, `Documents/universal-adblock`), **либо** скачайте готовую сборку из раздела **Releases**.

> **Важно:** Не удаляйте распакованную папку после установки — браузер загружает расширение напрямую из неё.

### 1. Google Chrome
1. Введите в адресной строке `chrome://extensions/` и нажмите Enter.
2. Включите **Режим разработчика** (переключатель в правом верхнем углу).
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку с расширением (корневую папку или `dist/yandex-opera-edge-chrome`).
5. Закрепите иконку **UltiBlock Pro** через значок пазла 🧩 на панели браузера.

### 2. Яндекс Браузер (Yandex Browser)
1. Введите в адресной строке `browser://extensions/`.
2. Включите **Режим разработчика** в правом верхнем углу.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку с расширением (корневую или `dist/yandex-opera-edge-chrome`).

### 3. Opera / Opera GX
1. Введите в адресной строке `opera://extensions/`.
2. Включите **Режим разработчика** (переключатель справа сверху).
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку с расширением (корневую или `dist/yandex-opera-edge-chrome`).
5. *(Рекомендуется)* Отключите встроенный блокировщик рекламы Opera на YouTube, чтобы избежать конфликтов.

### 4. Microsoft Edge
1. Введите в адресной строке `edge://extensions/`.
2. Включите **Режим разработчика** (переключатель в левом меню).
3. Нажмите **Загрузить распакованное**.
4. Выберите папку с расширением (корневую или `dist/yandex-opera-edge-chrome`).

### 5. Brave / Vivaldi / Arc (другие Chromium-браузеры)
1. Откройте `chrome://extensions/` (или `brave://extensions/` / `vivaldi://extensions/`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** и выберите папку с расширением.
4. *(Для Brave)* Рекомендуется отключить Brave Shields на YouTube, чтобы не было двойной фильтрации.

### 6. Mozilla Firefox (Gecko MV3)
> Предварительно соберите порт командой `node build-ports.js` (или возьмите папку `dist/firefox/` из Releases), так как Firefox требует отдельный `manifest.json`.

**Временная установка (обычный Firefox):**
1. Введите в адресной строке `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение...**
3. Выберите файл `dist/firefox/manifest.json`.

**Постоянная установка (Firefox Developer Edition / Nightly / Waterfox / Floorp / LibreWolf):**
1. Откройте `about:config`, найдите `xpinstall.signatures.required` и переключите на `false`.
2. Откройте `about:addons` → значок шестерёнки ⚙️ → **Установить дополнение из файла...**
3. Выберите `dist/ultiblock-pro-firefox.xpi`.

## ⌨️ Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `Alt + D` | Включить / выключить Smart Dark Reader на текущем сайте |
| `Alt + P` | Включить / выключить «Картинка в картинке» (PiP) на YouTube |
| `Esc` | Отменить режим выбора элемента |

## 🛠️ Сборка портов под браузеры

Требуется [Node.js](https://nodejs.org/):

```bash
node build-ports.js
```

В папке `dist/` появятся готовые сборки и архивы:
- `dist/yandex-opera-edge-chrome/` + `ultiblock-pro-yandex-opera-edge-chrome.zip`
- `dist/firefox/` + `ultiblock-pro-firefox.zip` + `ultiblock-pro-firefox.xpi`
